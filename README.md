# Question 4: To-Do List Application (React.js)

A clean, modular **Task & Deliverable Workspace** built with **React 18** and **Vite**.

## Features

- Create tasks with Category, Priority (`High`, `Medium`, `Low`), and optional Due Date.
- Inline editing for task title, priority, and due date.
- Status tabs (`All`, `Pending`, `Completed`), search bar, priority filter, and sort selector (`Newest`, `Highest Priority`, `Earliest Due Date`).
- Live completion rate progress bar and KPI counters.
- Persistent browser storage via custom `useLocalStorage` hook.

## Setup & Run

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
